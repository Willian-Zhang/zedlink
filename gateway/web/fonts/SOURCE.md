# Terminal icon fallback

Subset of Symbols Nerd Font Mono, Nerd Fonts v3.4.0:
https://github.com/ryanoasis/nerd-fonts/tree/v3.4.0/patched-fonts/NerdFontsSymbolsOnly

Only Seti/original U+E5FA–E6B7 and Font Awesome U+F000–F2E0 icons are included. See the adjacent MIT and Font Awesome font OFL 1.1 notices (upstream also documents CC BY 4.0 for its SVG/JS icons). Other private-use glyphs may still require the user’s specific shell font. Emoji are provided by the operating system’s emoji font.

The subset retains upstream font naming. Generated with fontTools 4.62.1; TTF for native clients and WOFF2 for the browser.
