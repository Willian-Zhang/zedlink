# Terminal icon fallback

Subset of Symbols Nerd Font Mono, Nerd Fonts v3.4.0:
https://github.com/ryanoasis/nerd-fonts/tree/v3.4.0/patched-fonts/NerdFontsSymbolsOnly

Included ranges: Seti/original U+E5FA–E6B7 (MIT), Devicons U+E700–E8EF (MIT), Font Awesome U+F000–F2E0 (font OFL 1.1), Octicons U+F400–F533 (MIT), and Material Design U+F0001–F1AF0 (Apache 2.0). Adjacent notices accompany these glyphs, including the complete Apache license. Font Logos and other icon sets are excluded. Emoji use the operating system font.

The subset retains upstream font naming. Generated with fontTools 4.62.1; TTF for native clients and WOFF2 for the browser. Run `python3 tools/subset_terminal_font.py /path/to/SymbolsNerdFontMono-Regular.ttf` with the v3.4.0 upstream font to regenerate assets and native notices.
